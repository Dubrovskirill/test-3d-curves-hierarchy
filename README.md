# test-3d-curves-hierarchy

Данный проект представляет собой реализацию иерархии трехмерных геометрических кривых (кругов, эллипсов и спиралей) на языке C++17. Программа считывает данные из файла, вычисляет точки и производные, фильтрует и сортирует объекты согласно заданным критериям.

## Архитектура решения

Проект построен на принципах SOLID и ООП:

* Интерфейс `ICurve`: Определяет контракт для всех кривых. Содержит чистые виртуальные функции `getPoint(t)` и `getDerivative(t)`, а также общие метаданные (ID и Name).


* Все типы кривых (`Circle`, `Ellipse`, `Helix`) могут использоваться через указатель на базовый класс `ICurve` без нарушения логики программы.


* Управление памятью: Используются умные указатели `std::shared_ptr`. Это исключает утечки памяти и необходимость явного вызова `delete`.


* Класс `Parser` инкапсулирует логику чтения файлов. Он устойчив к некорректным данным: если параметры кривой физически неверны (например, отрицательный радиус), строка пропускается с выводом ошибки, но программа продолжает работу.



## Математика

Координаты точек и векторы производных вычисляются параметрически для параметра :

### 1. Circle 

* **Точка**:  $C(t) = \{R \cdot \cos(t), R \cdot \sin(t), 0\}$ (относительно центра).


* **Производная**:  $C'(t) = \{-R \cdot \sin(t), R \cdot \cos(t), 0\}$



### 2. Ellipse

* **Точка**:  $C(t) = \{a \cdot \cos(t), b \cdot \sin(t), 0\}$, где $a$ и $b$   — малая и большая полуоси.


* **Производная**: $C'(t) = \{-a \cdot \sin(t), b \cdot \cos(t), 0\}$



### 3. 3D Helix 

* **Точка**:  $C(t) = \{R \cdot \cos(t), R \cdot \sin(t), \frac{S \cdot t}{2\pi}\}$, где $S$ — шаг (step)


* **Производная**: $C'(t) = \{-R \cdot \sin(t), R \cdot \cos(t), \frac{S}{2\pi}\}$



## Запуск и тестирование

Программа является консольным приложением. Путь к файлу данных должен передаваться как аргумент командной строки.

### Запуск из Visual Studio

1. Откройте решение `.sln`.
2. Нажмите правой кнопкой на проект в обозревателе решений -> Properties.
3. Перейдите в Configuration Properties -> Debugging.
4. В поле Command Arguments введите путь к тестовому файлу в кавычках, например:
`"C:\путь\к\файлу\curves_to_check.txt"`
5. Запустите проект .

### Запуск из консоли (Windows)

Находясь в корневой папке проекта, выполните команду, указав путь к исполняемому файлу и целевому файлу данных:

```powershell
.\x64\Debug\CurvesApp.exe "полный_путь_к_файлу.txt"

```

### Структура входного файла

1. Первая строка: общее количество кривых.


2. Последующие строки: тег типа (`C`, `E`, `H`), ID, имя в кавычках, координаты центра (X, Y, Z) и специфические параметры (радиусы/шаг).
